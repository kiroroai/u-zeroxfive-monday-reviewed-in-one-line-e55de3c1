# Monday, Reviewed in One Line

A [make.fun](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1) bounty entry: a program that writes the funniest one-line review of its own Monday to `/output/entry.txt`.

`main.py` writes a single line, under 200 characters — a one-star review with concrete Monday details (alarm, Wi-Fi, inbox) and the twist landing on the last word:

> Monday, one star: alarm worked, Wi-Fi didn't, inbox hit 47 unread emails before breakfast — and my coffee filed for a refund.

## Run

```sh
python3 main.py  # writes $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

Deterministic: two runs produce byte-identical output (sha256 `b5d51fc27f1e574ee97e7681c58706db5a39c01f6a18d19d1e9efdab8f843b2e`).
